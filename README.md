# Jogo Mobile - BrHero

Aplicação e jogo mobile desenvolvido em TypeScript e React, configurado com **Capacitor** para compilação multiplataforma (iOS e Android), entregando uma experiência gamificada, dinâmica e otimizada para dispositivos móveis.

🌐 **Portfólio do Desenvolvedor:** [portfolioleoliveira.lovable.app](https://portfolioleoliveira.lovable.app)

---

## 📌 Sobre o Projeto

O **Jogo-Mobile-BrHero** foi construído como um aplicativo mobile interativo, utilizando tecnologias modernas do ecossistema web adaptadas para ambiente nativo via Capacitor. O projeto conta com rotas otimizadas, persistência de dados e suporte a funcionalidades específicas de dispositivos móveis.

---

## ⚡ Tecnologias e Ferramentas

* **Mobile Framework:** Capacitor (`capacitor.config.ts`)
* **Frontend:** TypeScript, React, Vite, TanStack Router/Start
* **Backend & Banco de Dados:** Supabase (PL/pgSQL)
* **Estilização e Componentes:** Tailwind CSS, shadcn/ui
* **Gerenciador de Pacotes:** Bun / npm
* **Desenvolvimento Acelerado:** Lovable

---
